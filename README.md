# CS 417 MP0

Unity project for CS 417 MP0.

## Open the project

- Unity version: `6000.5.6f1`
- In Unity Hub, choose **Add > Add project from disk** and select this folder.
- The current working scene is `Assets/Scenes/Menu.unity`.
- Open this folder in Visual Studio Code when editing C# scripts.

## Moving between computers

Pull before starting work. After saving your Unity scene and project, commit and push before switching computers. Avoid editing the same project on both computers at the same time.

Unity will rebuild the untracked `Library` folder when the project is first opened on another computer.
